Verziókövető rendszerek legfontosabb

  • Verziókezelés: lehetővé teszi a szoftverprojekt forráskódjában és fájljaiban végrehajtott módosítások kezelését és nyomon követését.
  • Teljes változásnapló: lehetővé teszi, hogy részletes nyilvántartást vezessen a projekten végrehajtott összes módosításról, beleértve azt is, ki végezte az egyes változtatásokat, mikor és mi változott.
  • Hatékony együttműködés: lehetővé teszi, hogy több fejlesztő párhuzamosan dolgozzon egy projekten anélkül, hogy zavarná egymást.
  • Visszaállítás: lehetővé teszi, hogy visszalépjen az időben, és visszaállítson egy korábbi verziót, különösen kritikus hibák vagy visszavonandó döntések esetén.

GitHub használatának legfontosabb parancsai

  • git init A projekt-tárhelyhez a Git rendszert inicializálja.
  • git clone [url]: A létező Git repo-t a saját gépedre klónozza.
  • git add [file] A megadott fájlt a Git "stage"-re helyezi.
  • git commit -m [commit message]: Az összes változást commit-olja.
  • git push: A commit-olt változásokat a távoli repo-ba feltölti.
